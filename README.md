## Paradise Nursery - Online Plant Shopping Application

This project is an online plant shopping application called **Paradise Nursery**.

The application allows users to browse different categories of house plants, view plant details, and add plants to a shopping cart.

### Features

* Landing page with a button to access the product listing page
* Navigation bar for easy navigation
* Multiple categories of house plants
* Plant cards with images, names, descriptions, and prices
* Add to Cart functionality
* Shopping cart with selected products
* Increase and decrease product quantities
* Delete products from the cart
* Calculate individual product totals
* Calculate the total cart amount
* Continue Shopping button
* Checkout button

### Technologies Used

* React
* JavaScript
* Redux Toolkit
* React Redux
* CSS
* Vite
